# Autonomous Live Ops AI Agents for Dynamic Game Experiences

Sample code and assets for the **self-paced version** of the [Autonomous Live Ops AI Agents for Dynamic Game Experiences](https://catalog.us-east-1.prod.workshops.aws/workshops/473b5f25-4081-4f1f-a159-798b53285f00/en-US) workshop.

## Overview

Build autonomous AI agents for game LiveOps using Strands Agents SDK, Amazon Bedrock AgentCore, S3 Vectors, and MCP. You will create RAG-enhanced agents that analyze player behavior, discover segments, and generate targeted campaign recommendations automatically.

## Getting Started

1. Follow the [self-paced workshop instructions](https://catalog.us-east-1.prod.workshops.aws/workshops/473b5f25-4081-4f1f-a159-798b53285f00/en-US/getting-started/self-paced) to set up your AWS environment.
2. Clone this repository into your workshop environment.
3. Proceed through the labs using the assets provided here.

## ⚠️ Security Disclaimer
